🧩 CollabBoard

A real-time collaborative project management board inspired by tools like Trello.
Users can create boards, manage tasks, invite collaborators, and see updates instantly via WebSockets.

⸻

🚀 Live Demo
	•	Frontend: https://main.d1lp5i4kfiauc2.amplifyapp.com
	•	Backend: https://collabbackend-env.eba-cdu8h94w.us-east-2.elasticbeanstalk.com

⸻

✨ Features

🗂️ Boards & Columns
	•	Create and manage boards
	•	Add, edit, and delete columns
	•	Drag-and-drop cards between columns

📝 Cards
	•	Create, update, and delete cards
	•	Track card content and status
	•	Real-time updates across users

👥 Collaboration
	•	Invite users to boards
	•	Accept / decline board invitations
	•	Role-based board membership

⚡ Real-Time Updates
	•	WebSocket-powered sync
	•	Live updates for:
	•	Card creation, movement, deletion
	•	Column updates
	•	Board invitations

🔔 Notifications
	•	Activity center for board invites
	•	Real-time invite delivery

⸻
